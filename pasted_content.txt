# Build RepoLens — AI Codebase Navigator

Build a polished, production-style web application called **RepoLens**.

## 1. Product concept

RepoLens is an AI-powered tool that helps developers understand an unfamiliar GitHub repository and discover a realistic first contribution.

The core experience:

**GitHub Repository → Codebase Understanding → Visual Architecture → Contribution Recommendation → Implementation Plan → GitHub Issue**

The product should feel like a tool created from scratch by a professional developer team, NOT like an AI chatbot wrapper.

The UI, branding, navigation, component system, interactions, and information architecture must all be original.

Do not copy the UI or visual design of existing repository-analysis products.

---

# 2. Primary user story

A developer discovers an unfamiliar open-source GitHub repository.

Instead of spending an hour reading the codebase, they paste the repository URL into RepoLens.

RepoLens analyzes the repository and gives them:

1. What the project does
2. Technology stack
3. Repository structure
4. Visual architecture
5. Important files
6. How major components connect
7. Beginner-friendly contribution opportunities
8. Recommended files to modify
9. Implementation steps
10. A ready-to-use GitHub Issue

The most important interaction is:

> **"Find my first contribution."**
